# FR24 Standard API

Локальный сборщик данных Flightradar24 LiveFeed с HTTP API.

## Возможности

- Опрос FR24 каждые 10 секунд.
- Получение live-позиций через FlightRadarAPI.
- Кэширование координат и телеметрии воздушных судов.
- Удаление устаревших позиций.
- HTTP API и веб-панель на порту 8765.
- Карта и таблица самолётов с высотой, скоростью, курсом и расстоянием.
- Карточка выбранного самолёта: регистрация, ICAO24, модель, авиакомпания, маршрут, аэропорты, расписание, статус и дополнительные поля FR24.
- Подробности конкретного рейса запрашиваются отдельно при выборе самолёта и кэшируются.
- Фильтрация по расстоянию в морских милях (NM).

## Требования

- Windows 10 / Windows Server 2019 или новее.
- Python 3.11 или новее.
- requests 2.31.0 или новее.
- FlightRadarAPI 1.7.1 или новее.

## Установка

    git clone https://github.com/alisatsyplyarova-art/FR24_Standard_API.git
    cd FR24_Standard_API
    python -m venv venv
    .\venv\Scripts\Activate.ps1
    pip install -r requirements.txt

## Настройка

Создайте radar_config.json на основе radar_config.example.json. Укажите latitude, longitude и radius_km. HAR-файл для текущей версии не требуется.

## Запуск

    python main.py

## Веб-панель

После запуска откройте в браузере `http://localhost:8765/`.
Панель использует самолёты, полученные из FR24 Standard API; подложка карты загружается из OpenStreetMap. Выбор самолёта на карте или в таблице открывает единую карточку с вкладками «Самолёт», «Авиакомпания», «Маршрут», «Полёт» и «Все поля».
Обновление списка выполняется автоматически каждые 10 секунд.

## API

- GET /health — состояние сервера, число самолётов в кэше и активная область сбора.
- GET /aircraft — все воздушные суда в кэше.
- GET /aircraft/{fr24_id}/details — подробная информация о выбранном рейсе; детали загружаются при первом открытии карточки.
- GET /aircraft/{fr24_id}/details — подробные сведения о выбранном рейсе (запрос к FR24 выполняется при первом открытии карточки).
- GET /v2/lat/{latitude}/lon/{longitude}/dist/{distance} — запрос ESP32; расстояние передаётся в морских милях (NM).

### Работа с Flight Radar-D & Clock 1.1.127

ESP32 передаёт серверу текущие координаты центра радара и выбранный радиус через
`/v2/lat/{latitude}/lon/{longitude}/dist/{distance}`. Сервер использует эти параметры
не только для фильтрации ответа, но и для формирования области следующего запроса
к FR24 LiveFeed. Поэтому данные больше не ограничены постоянной областью из
`radar_config.json`.

`radar_config.json` служит начальной областью сбора до первого запроса от ESP32.
После первого запроса активная область меняется вслед за центром и масштабом радара.
В журнале коллектора выводятся текущие координаты и радиус; `/health` показывает
активную область в поле `active_area`.

Если к серверу подключено несколько радаров с разными координатами, используется
область последнего поступившего запроса (режим одного активного радара).

fr24_id — внутренний идентификатор FR24, не ICAO HEX. ICAO24 берётся из отдельного поля `icao_24bit`, если FR24 его передаёт.

FR24 не гарантирует наличие всех полей у каждого рейса. Неизвестные значения остаются пустыми; страна авиакомпании показывается только при наличии соответствующего поля в ответе источника.
