## Критерии готовности

- Каждый ESP32 видит самолёты только в своей области.
- Запрос одного радара не перезаписывает область другого.
- Пересекающиеся зоны дают одну объединённую область без потери покрытия.
- Удалённые зоны опрашиваются отдельно.
- При сбое FR24 HTTP API продолжает отдавать последнюю доступную позицию в пределах срока жизни кеша.
- Существующая прошивка продолжает разбирать ответ без изменений.
- Нагрузка проверена измерениями; число устройств не объявляется гарантированным до теста.
